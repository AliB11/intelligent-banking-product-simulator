# گزارش بازبینی فنی و تجربه کاربری سیمرغ

تاریخ: ۲۰۲۶-۱۰-۰۹ • دامنه: کد محلی Next.js، موتور مالی و تحلیل، API، PostgreSQL، CI، رابط فارسی و RTL.

این گزارش گواهی امنیت، صحت مدل بانکی یا انطباق حقوقی نیست. تغییرات روی همان شاخهٔ کاری اعمال شده‌اند؛ هیچ داده یا سرویس production تغییر نکرده است.

## تجربه کاربری

- میز کار سه‌مسیره برای طراحی، سفر مشتری و مقایسه؛ توضیح هدف هر مسیر پیش از ورود به فرم‌های فنی.
- ناوبری فعال با `aria-current` و پیمایش افقی در عرض محدود.
- پیوند پرش به محتوا، فوکوس قابل‌مشاهده، معنای switch و وضعیت انتخاب دکمه‌ها برای فناوری کمکی.
- رعایت reduced-motion، صفحه loading و error با مسیر بازیابی.
- بازیابی پارامترهای اجرای ذخیره‌شده در آزمایشگاه؛ هشدار روشن هنگام تفاوت پارامترهای جدید و نتایج قبلی.
- توضیح غیرزنده‌بودن داده‌های کلان و آموزشی‌بودن نتایج.

## شواهد بررسی

- `npm test`: ده تست شامل ۱۲۶ ترکیب روش اقساط/مدت/نرخ، APR، حمله به prototype، ورودی‌های نامعتبر، حفظ اندازه بازار، قطعیت seed، همه الگوها، استرس، تطابق امتیاز بهینه‌ساز و خطاهای API.
- `npm run lint`، `npm run typecheck`، `npm run build` و `git diff --check` اجرا شده‌اند.
- `SMOKE_BASE_URL=http://127.0.0.1:3000 npm run test:smoke`: روی سرور production محلی و PostgreSQL آزمایشی ۱۸.۴ اجرا شد؛ سلامت، CRUD، شبیه‌سازی، هر سه تحلیل، نامعتبر شدن نتیجه پس از ویرایش، هفت مسیر صفحه و حذف محصول را پوشش می‌دهد. محصول تست در پایان حذف می‌شود.
- `npm audit --omit=dev`: صفر آسیب‌پذیری شناخته‌شده در زمان بررسی.
- ممیزی کامل ابزارهای توسعه هنوز ۹ مورد وابستگی انتقالی (۵ high در زنجیره braces/ESLint و ۴ moderate در زنجیره esbuild/Drizzle Kit) گزارش می‌کند. پیشنهاد خودکار npm شامل downgrade ناسازگار است و بدون بررسی اعمال نشده است.
- آزمون تصویری یا تعاملی مرورگر واقعی انجام نشده است؛ بررسی HTTP جایگزین آزمون مرورگر و فناوری کمکی نیست.

## موارد باقی‌مانده پیش از بهره‌برداری واقعی

1. **بحرانی برای انتشار عمومی:** طبق SECURITY.md احراز هویت، مالکیت محصول/تفکیک کاربران، مجوزها، کنترل origin/CSRF و rate limit وجود ندارد. پیش‌نمایش فقط برای داده مصنوعی است؛ سرویس عمومی بانکی محسوب نمی‌شود.
2. **ظرفیت:** محاسبات همگام در Node و مرورگر انجام می‌شوند. برای بار واقعی worker، صف، بودجه CPU، لغو کار و محدودیت هم‌زمانی لازم است. سقف ورودی جلوی همهٔ حملات محروم‌سازی از سرویس را نمی‌گیرد.
3. **حاکمیت مدل:** جمعیت، PD/LGD، تقاضا، سود قرض‌الحسنه، انقضای امتیاز و رفتار مشتری تقریبی‌اند. کالیبراسیون، backtesting و بازبینی متخصص مالی انجام نشده است. IRR و VaR نیازمند تعریف و مستندات مصوب کسب‌وکار هستند.
4. **مقررات:** اعداد ۱۴۰۵، نرخ‌ها و ادعاهای انطباق کاتالوگ در این بررسی با منبع رسمی تطبیق داده نشده‌اند؛ دسترسی وب این محیط نیز محدود است. برچسب انطباق را تأیید حقوقی ندانید.
5. **داده و عملیات:** self-healing DDL هنوز برای production مناسب مهاجرت‌های نسخه‌دار نیست. pagination، سیاست نگهداری نتایج، ایندکس‌های متناسب با بار، پشتیبان‌گیری/بازیابی و پایش لازم‌اند.
6. **UX:** فرم‌های طولانی به آزمون با کاربران فارسی‌زبان، مرورگر موبایل، کنتراست و صفحه‌خوان نیاز دارند. هشدار کهنگی فعلاً خروجی مونت‌کارلو را پوشش می‌دهد؛ snapshot مستقل پارامترها برای هر تب تحلیل پیشنهاد می‌شود.
7. **بهینه‌ساز:** جستجوی تصادفی/ابتکاری تضمین بهینهٔ سراسری یا بهبود در اجرای نهایی نمی‌دهد. باید نتیجه و امکان‌پذیری حقوقی قبل از اعمال بازبینی شود.

## اجرای مجدد

```sh
npm ci
# DATABASE_URL را در محیط یا .env تنظیم کنید.
npm test
npm run lint
npx next typegen
npm run typecheck
npm run build
npm run start -- --hostname 0.0.0.0
# در ترمینال دیگر، فقط روی دیتابیس تست:
SMOKE_BASE_URL=http://127.0.0.1:3000 npm run test:smoke
```

پایگاه داده و ابزار PostgreSQL مورد استفاده برای پیش‌نمایش خارج از مخزن و در پوشهٔ cache موقت‌اند. داده‌های آن‌ها جزو تغییرات Git نیستند.
